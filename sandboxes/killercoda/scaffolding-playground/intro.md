# Welcome to the Hexastack Scaffolding Playground!

In this interactive scenario, you will experience Hexastack's zero-install scaffolding engine:

1. Scaffold a clean Hexagonal architecture microservice using `hexastack new`.
2. Generate CQRS command and query pipelines with `hexastack add`.
3. Verify test symmetry, `__all__` sorting, and import linter boundaries via `hexaqual sanity`.

Click **Start** to begin!
