# Developer Tools & Quality Engineering

Hexastack leverages [**Hexaqual**](https://github.com/TheTrueSCU/hexaqual) (`hexaqual`), the enterprise quality, governance, and release engineering suite for Python monorepos and hexagonal architecture projects.

For complete documentation on Hexaqual inspection tools, PR dashboards, mutation testing, and sanity checks, see the [Hexaqual Documentation](https://dopplereffect.us/hexaqual/).
