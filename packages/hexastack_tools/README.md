# Hexastack Tools

Developer tooling, code-scanning analysis, repository governance, and CI automation suite for Hexastack.

## Architecture

`hexastack-tools` dogfoods Hexastack's own hexagonal architecture (`hexastack-core`, `hexastack-cqrs`, `hexastack-cli`) with clean domain models, port abstractions, pluggable presenters, and CQRS command pipelines.
